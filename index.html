Panduan Upload Aplikasi ke GitHub Pages

Aplikasi ini dirancang sebagai Single-File Web App (`index.html`), sehingga sangat mudah untuk di-upload dan di-publish gratis melalui **GitHub Pages**:

  1. Buat Repository Baru di GitHub:

    Buka github.com, klik tombol New Repository, beri nama misal form-karyawan-glori, lalu tentukan Public.

  2. Upload File Code:

    Simpan seluruh kode aplikasi ini sebagai file bernama index.html. Di repository GitHub Anda, pilih Upload files dan unggah index.html tersebut.

  3. Aktifkan GitHub Pages:

    Masuk ke menu Settings repository → pilih menu Pages di bilah kiri → pada bagian Branch pilih main / root → klik Save.

  4. Aplikasi Siap Digunakan Online:

    Dalam 1-2 menit, GitHub akan memberikan URL link online publik (contoh: https://username.github.io/form-karyawan-glori/) yang siap diakses di mana saja.
